# Evaluation

| File | What it is |
|---|---|
| `protocol.md` | The 10–15 minute participant session: consent script with separate opt-outs for data, quotes, and transcripts; task; questions; what to record |
| `participant_data_template.csv` | Empty template. Copy it to `participant_data.csv` and fill in one row per participant |
| `comparison_framework.md` | Conditions A (generic advice), B (general chatbot, same model), and C (SkillSim) on the same scenario; criteria; hypotheses H1–H5 written before testing |
| `comparison_ratings_template.csv` | Empty template for human A/B/C ratings. Copy it to `comparison_ratings.csv` |
| `results_summary.md` | **Real participant results only.** Generated by `python -m scripts.summarize_evaluation`. It currently says no data has been collected |
| `internal_evaluation.md` / `.json` | **Internal evaluation, no humans:** automatic proxies on scripted runs with the real model. Generated by `python -m scripts.internal_evaluation` |

**Findings are kept in separate places.** Participant results go only in `results_summary.md`. Machine-measured proxies go only in `internal_evaluation.md`. Hypotheses stay in `comparison_framework.md` until data supports or contradicts them.

**Privacy.** `participant_data.csv` should contain participant IDs only, never names. If you commit it, commit only rows with `consent_data = yes`, and make sure the `feedback` text of anyone with `consent_quote = no` contains nothing they'd mind a reader seeing (or leave it out).
